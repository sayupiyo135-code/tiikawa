もふもふワークワールド v0.1

ファイルは別々です。
1. package.json
2. server.js
3. public/index.html
4. public/style.css
5. public/game.js

起動:
npm install
npm start

Render:
Build Command: npm install
Start Command: npm start

秘密の裏格闘パスワードは Render の環境変数 FIGHT_PASSWORD で設定できます。
未設定の場合は hiddenfight です。

※ v0.1プロトタイプです。オンライン状態・HP・空腹・草・ドロップ・死亡判定はサーバー側で管理する構成です。
